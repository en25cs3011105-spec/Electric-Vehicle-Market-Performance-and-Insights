# EV Market Insights Website

1. Create a public GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, `main`, and `/(root)`, then Save.
5. GitHub will display your public website URL.

The Tableau workbook must remain published and public for the embedded dashboard to load.
